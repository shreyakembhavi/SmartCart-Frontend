# SmartCart Expo Client

The complete project overview, architecture, contribution details, and setup instructions are available in the [repository README](../README.md).

Quick start:

```bash
npm install
cp .env.example .env
npm start
```

Set `EXPO_PUBLIC_API_URL` in `.env` before starting the application. When testing through Expo Go on a physical phone, use the development computer's LAN address rather than `localhost`.
